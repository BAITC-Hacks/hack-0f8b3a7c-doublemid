# Изменения и проверка поставки

## Исправленные пробелы

| Было | Стало |
|---|---|
| Свободный переключатель бизнес/студент | Вход, серверная сессия, проверка прав каждого действия |
| Отдельная копия каталога для каждого браузера | Единый каталог между аккаунтами |
| Клиент выбирал идентификатор команды | Команда определяется аккаунтом на сервере |
| Один экран для обеих ролей | Экран входа и отдельные обзоры бизнеса/студента |
| Бизнес мог сразу начислить баллы | Сначала отчёт выбранной команды, затем проверка бизнеса |
| Только карточки откликов | Карточки и таблица сравнения |
| Не было подборки по интересам | Рекомендации рабочих задач без назначения команды |
| Ручное применение одной миграции | Идемпотентная команда db:migrate, включая аккаунты |

## Автоматически проверено

- TypeScript и ESLint: без ошибок и предупреждений.
- Производственная сборка всех трёх маршрутов `/`, `/api/auth`, `/api/workspace`.
- Доменные проверки: веса, границы уровней, три вопроса, резервный AI-ответ.
- 9 проверок валидации тела запроса и восстановления формы.
- 17 проверок AI-контракта с имитацией сетевых ответов (без расходов).
- Собранный Worker: SSR и отдача клиентских ресурсов.
- API: две роли, разные команды, общий каталог, приватность черновиков и предложений.
- API: запрещённые действия, подмена teamId, чужой отчёт, недопустимые URL.
- API: публикация, отклик при низком рейтинге, ручной выбор нескольких команд и отклонение.
- API: отчёт выбранной команды, подтверждение, ровно 20 баллов, повтор без начисления.
- API: конкурирующие правки, идемпотентность, некорректный JSON, Origin, поддельная сессия и отзыв сессии при выходе.

Тесты API для этой поставки запускались на отдельной временной D1 через `npm run test:built`. Данные пользовательского показа не затрагивались. Сборка сама по себе не доказывает доступность внешнего хостинга.

## Проверка в браузере

Chromium, два независимых браузерных контекста: вход бизнеса и студента → конструктор с уточнениями → подтверждённая публикация → отклик → выбор → отчёт студента → подтверждение → 20 баллов. Проверены таблица сравнения, ширина 390 px и отсутствие ошибок выполнения в обеих страницах. При визуальном просмотре исправлено обрезание уровня готовности в компактной подборке. Скриншоты находятся в `docs/screenshots/`.

## Практические границы

Демо-аккаунты публичные, без регистрации и восстановления пароля. Один бизнес-аккаунт и пять учебных команд, один подтверждаемый этап на отклик. Нет почты и внешней проверки прототипов. Ссылки example.com — заглушки. Доступ к реальному OpenAI и платные запросы не проверялись. GitHub и внешний сайт не обновлялись: прав доступа в сессии не было. Окончание текста кейса после уровня 70–89 не предоставлено.
