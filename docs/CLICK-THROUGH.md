# Как проверить AI Sana по кликам

## Перед началом

Откройте адрес опубликованного сайта, который указан в сообщении о размещении. Если сайт ещё не размещён, текущий локальный адрес — http://localhost:4174/ (доступен, пока запущен сервер на этом компьютере).

Для полного сценария используйте один браузер и переключатель ролей справа сверху. Это учебная среда: в другом браузере будет отдельный набор данных. Все компании, контакты и достижения в сценарии вымышленные. Ссылки example.com нужны только для проверки формы, рабочих прототипов за ними нет.

Реальные запросы к OpenAI пока выключены. Уточняющие вопросы работают в явно обозначенном демо-режиме. Платные запросы требуют отдельного согласования.

## 1. Проверить готовые примеры — 1 минута

При первом открытии должны быть 5 задач, 5 команд и 5 откликов. Карточки отсортированы по готовности:

| Задача | Организация | Баллы |
|---|---|---:|
| Прогноз спроса без лишних запасов | Retail Lab | 100 |
| Помощник по вопросам кампуса | Campus Service | 85 |
| Маршруты доставки без лишних километров | Green Route | 70 |
| Заявки клиентов в одном окне | Service Point | 45 |
| Учёт раздельного сбора отходов | Eco Campus | 20 |

1. В поиске введите «заявки»: останется карточка Service Point.
2. Нажмите **Сбросить**. В фильтре **Тема** выберите «Экология»: останется Eco Campus.
3. Снова **Сбросить**. В фильтре готовности выберите **0–39 · Уточнить**: карточка с 20 баллами доступна.
4. Откройте карточку: незаполненные сведения обозначены «Нужно уточнить у бизнеса».
5. Закройте карточку крестиком и сбросьте фильтры.

## 2. Создать задачу бизнеса — 3 минуты

1. Роль сверху — **Бизнес**. Нажмите **Создать задачу**. Новая задача также доступна через **Мои задачи → Новая задача**. Если есть незавершённая работа, её можно восстановить кнопкой **Продолжить заполнение**; замена требует подтверждения.
2. Вставьте в описание:

   «Заявки клиентов приходят в почту и теряются при передаче между менеджерами. Хотим автоматизировать обработку».

3. Тема — **Сервис**. Нажмите **Уточнить задачу**.
4. Должно появиться не менее трёх вопросов и сообщение о демо-режиме. Ответьте по таблице ниже. Необязательно заполнять всё: недостающие поля можно дописать на следующем шаге.

| Поле | Ответ для копирования |
|---|---|
| Потребность | Собирать обращения в единой очереди и распределять их по категориям. |
| Пользователи | Три менеджера клиентского сервиса и руководитель отдела. |
| Данные и материалы | 100 синтетических заявок с категориями в CSV, доступ через куратора. |
| Ограничения | Прототип за две недели. Использовать только синтетические данные. |
| Ожидаемый результат | Веб-форма, очередь заявок и фильтр по статусу. |
| Критерии успеха | Все 20 тестовых заявок сохранены, не менее 18 правильно классифицированы. |
| Контакт бизнеса | Куратор учебного кейса: mentor@example.com |
| Формат взаимодействия | Консультация раз в неделю и письменный отзыв в течение двух дней. |

5. Нажмите **Собрать карточку**. Название — **ТЕСТ — единая очередь заявок**, организация — **Demo Service**.
6. Проверьте все девять полей. Контекст уже заполнен исходным описанием. При заполнении всех полей предварительная оценка — **100/100**.
7. Пока галочка подтверждения не установлена, публикация недоступна.
8. Установите **Я проверил(а) заполненные сведения…** и нажмите **Опубликовать задачу**.
9. Ожидаемый результат: карточка опубликована с 100 баллами; в новом пространстве теперь шесть задач. Закройте открывшуюся карточку.

## 3. Отправить отклик команды — 1 минута

1. Вверху переключитесь на **Студенческая команда**, команда — **Qadam**.
2. Найдите **ТЕСТ — единая очередь заявок**, откройте её. Кнопка отклика находится вверху карточки и повторяется внизу.
3. Нажмите **Предложить решение** и заполните:

| Поле | Значение |
|---|---|
| Идея решения | Сделаем единую очередь обращений с категорией, ответственным и статусом. |
| План работы | Уточним процесс, соберём форму и очередь, проверим на 20 синтетических заявках. |
| Срок | 2 недели |
| Ссылка на прототип | https://example.com/demo-service |

4. Перед отправкой обновите страницу: заполненный отклик и выбранная команда должны восстановиться. Нажмите **Отправить предложение**. Во вкладке **Мои отклики** появится предложение со статусом **На рассмотрении**.

## 4. Выбрать исполнителя и подтвердить этап — 1 минута

1. Вернитесь в роль **Бизнес**, откройте **Отклики команд**.
2. Найдите предложение Qadam по задаче **ТЕСТ — единая очередь заявок**. Нажмите **Выбрать команду**.
3. Статус станет **Команда выбрана**, появится кнопка **Подтвердить этап**.
4. Нажмите её и введите учебное подтверждение:

   «Учебная проверка: на 20 синтетических заявках все обращения сохранены, 18 распределены по категориям верно».

5. Нажмите **Подтвердить и начислить баллы**.
6. Ожидаемый результат: **Этап подтверждён · +20 баллов**. Повторное начисление за этот отклик недоступно.
7. Переключитесь на **Студенческая команда → Qadam → Мои отклики**: подтверждение и баллы видны команде.

В реальном проекте этап подтверждают только после фактической проверки. Здесь мы проверяем механику на вымышленном примере.

## 5. Проверить сохранение

Обновите страницу и найдите тестовую задачу. Она должна остаться в каталоге, а решение и подтверждение — в **Откликах команд**. Выбранная роль после обновления может вернуться к «Бизнес»; это не потеря данных.

## 6. Проверить важные ограничения

- **Низкий рейтинг:** в роли команды откройте Eco Campus с 20 баллами. Кнопка **Предложить решение** должна быть доступна.
- **Обязательные поля отклика:** попробуйте отправить пустую форму. Предложение не должно сохраняться; браузер или приложение покажет ошибку.
- **Перепроверка карточки:** в роли бизнеса откройте тестовую задачу → **Редактировать карточку**, поставьте галочку и измените любое поле. Галочка должна сняться. Подтвердите ещё раз перед сохранением.
- **Неполные сведения:** в редактировании удалите значение «Данные и материалы». Предварительный рейтинг снизится со 100 до 80. Верните текст и подтвердите изменения.
- **Черновик:** **Мои задачи → Новая задача**, введите «ТЕСТ — черновик без публикации» и нажмите **Сохранить черновик**. Он виден в «Моих задачах», имеет 0 баллов и не появляется в каталоге команды.
- **Ручной выбор:** бизнес может выбрать несколько откликов по одной задаче, отклонить их или не выбирать никого. Автоматического назначения нет.

## Как повторить с чистого набора

Откройте сайт в другом браузере или приватном окне и, если требуется, войдите в свой аккаунт Sites. Новое учебное пространство получит исходные пять задач и пять откликов. Существующее пространство и его записи сохранятся. Обновление страницы само по себе данные не сбрасывает. Незавершённые карточка и отклик восстанавливаются в той же вкладке; галочку подтверждения нужно поставить заново. Для повторной проверки можно использовать фильтры статусов откликов.

## Если что-то не получилось

Запишите название шага, роль, название задачи, ожидаемый результат и текст ошибки. Это достаточно для воспроизведения. Никогда не прикладывайте API-ключ. Если показана ошибка загрузки, используйте **Обновить данные**. Демо-режим AI в этой версии ожидаем и не означает поломку.
