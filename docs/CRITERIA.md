# Проверка по кейсу AI Sana

| Требование | Реализация | Проверка |
|---|---|---|
| Свободный черновик | Конструктор, ввод описания и направления | API + доменные проверки |
| Не менее 3 вопросов | Контекстные вопросы, OpenAI при включении, резервный режим | Доменные и 17 AI-проверок |
| Полная редактируемая карточка | Название, контекст, потребность, пользователи, данные, ограничения, результат, успех, контакт, взаимодействие | Интерфейс и API |
| Ручное подтверждение | Галочка перед публикацией; сервер отвергает неподтверждённую публикацию | API |
| Баллы 0–100 по рекомендованным весам | 20/20/15/15/10/10/10, расчёт на сервере | Доменные проверки и API |
| Расшифровка и пробелы | Веса по полям, неподтверждённый предварительный рейтинг, подсказка следующего вопроса | Редактор и карточка |
| Пересчёт после изменений | Новый расчёт при подтверждённом сохранении | API: 10 → 45 |
| Общий каталог | Единая D1 для разных аккаунтов, скрытые личные черновики | Два независимых аккаунта в API |
| Сортировка и фильтры | По рейтингу, теме и уровню, поиск текста | Интерфейс |
| Любая команда может откликнуться | 5 аккаунтов команд, без лимита числа предложений, доступен низкий рейтинг | API |
| Идея, план и прототип | Обязательные поля, плюс срок, проверка HTTP(S) URL | API |
| Сравнение и ручной выбор | Карточки/таблица, выбрать/отклонить, несколько выбранных допустимы | API для нескольких команд |
| Нет автоматического назначения | Рекомендация только меняет порядок подборки; выбрать может бизнес | Проверка прав API |
| Баллы за реальный прогресс | Отчёт выбранной команды → проверка бизнеса → +20 однократно | API, повтор не начисляет баллы |
| Отдельные админ и пользователь | Вход по email/паролю, серверные роли, сессии с истечением | API, запреты на чужие действия |

Граница кейса: окончание критериев после «70–89 — готовая» не было предоставлено. Уровень 90–100 назван «Приоритетная», как в исходном проекте. Для демо предусмотрен один подтверждаемый этап на отклик; это достаточный MVP, не полноценный трекер проекта.
